How to remove an image background in three steps

Make a clean cutout with a browser-based or cloud AI model. Choose the processing option that fits your photo, check the result, and download a transparent PNG.

  1. Upload a photo Choose a JPEG, PNG, WebP, or GIF image up to 20 MB. You can also drag a file into the upload area.
  2. Choose how to process it Start with Browser for on-device processing, or select remove.bg or an available Hugging Face model for cloud processing.
  3. Compare and export Review the original and cutout, adjust the comparison slider, then download the transparent PNG. You can preview it against a solid color first.

Which background-removal engine should you choose?

Browser (Fast & Free) runs its model on your device and is the option to use when you do not want to upload the original image to a processing service. It works without a cloud API key.

remove.bg sends the image through LuminaBG's serverless proxy to the remove.bg API. It requires the site operator to configure an API key. Hugging Face models send the image to the configured Space and are useful when you want to compare different open-source models. Cloud availability and quotas depend on their providers.

Privacy tip: the Browser engine processes the image locally in your tab. The remove.bg and Hugging Face engines send the image to the selected remote service. Read the image processing and privacy details before choosing a cloud model.

Common questions

Can I remove a background without uploading my photo?

Yes. Select the Browser engine. It processes the image on your device; the cloud engines send it to the selected provider for processing.

What image formats and sizes are supported?

The upload tool accepts JPEG, PNG, WebP, and GIF files up to 20 MB.

What file do I download?

The result downloads as a PNG. Choose a transparent background for a cutout with transparency, or preview a solid-color composite before downloading.
