# Pairing on LuminaBG

Most changes here are written in pairs: one person drives, the other reviews
and shapes the commit. Both names go into the commit message.

## Credit your partner

Add a trailer at the end of the commit message, separated by a blank line:

```
Co-authored-by: Name <email-linked-to-github-account>
```

The email must be one that is added and verified on the partner's GitHub
account, otherwise GitHub will not link the credit to their profile.

## Working agreement

- One branch per change, opened as a pull request against `main`.
- The person who did not open the pull request merges it.
- Keep the diff small enough to review in one sitting.
